# Adding or correcting papers

1. Add the BibTeX entry to `survey.bib`, with a DOI if there is one.
2. Add a row to `papers.csv` using the same key.
3. Add a row to `taxonomy.csv` for each section the paper belongs in. Use the stage and category names from the README.
4. Open a pull request with a one-line note on the paper.

Papers added here after publication were not part of the survey's analysis.
